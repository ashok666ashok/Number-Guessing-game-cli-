# 🎮 Number Guessing Game - Node.js CLI

A classic, interactive command-line Number Guessing Game built with Node.js. The computer selects a random number between 1 and 100, and you must use logic and hints to guess it before running out of chances!

## ✨ Features

* **Interactive CLI:** Play entirely within your terminal.
* **Multiple Difficulty Levels:**
  * 🟢 **Easy:** 10 chances
  * 🟡 **Medium:** 5 chances
  * 🔴 **Hard:** 3 chances
* **Smart Feedback:** Receive immediate "greater than" or "less than" hints after every incorrect guess.
* **Win/Loss Tracking:** Keeps count of your attempts and alerts you when your chances are up.

### 🚀 Advanced Features

* **Endless Mode:** Play multiple rounds sequentially without restarting the application.
* **Speed Timer:** Tracks exactly how long it takes you to guess the correct number.
* **Hint System:** Request additional clues if you get completely stuck.
* **High Score Board:** Records and saves the fewest attempts taken per difficulty level.

## 📋 Prerequisites

* [Node.js](https://nodejs.org/) (v14.0.0 or higher recommended)

## ⚙️ Project Setup

Follow these steps to set up the project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ashok666ashok/Number-Guessing-game-cli-
   ```
2. **Run the game:**
   1. cd Number-Guessing-game-cli-
   2. npm install
   3. node main.js
